# Problem 8 — The Second Derivative

## Solution

\[
f'(x)=4x(x^2-2),\qquad f''(x)=12x^2-8.
\]
The critical points are \(-\sqrt2,0,\sqrt2\). The function increases on \((-\sqrt2,0)\) and \((\sqrt2,\infty)\), and decreases on \((-\infty,-\sqrt2)\) and \((0,\sqrt2)\). It has local minima \((\pm\sqrt2,-4)\) and a local maximum \((0,0)\).

Since \(f''=0\) at \(x=\pm\sqrt{2/3}\), the graph is convex for \(|x|>\sqrt{2/3}\) and concave for \(|x|<\sqrt{2/3}\). The inflection points are \(\left(\pm\sqrt{2/3},-20/9\right)\). The function is even and tends to \(+\infty\) at both ends, which completes the sketch information.
