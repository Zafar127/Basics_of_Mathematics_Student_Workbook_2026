# Problem 11 — Choosing an Integration Method

## Solution

1. Use substitution \(u=3x\), \(du=3dx\):
\[
\int\sin(3x)\,dx=-\frac13\cos(3x)+C.
\]
2. Use integration by parts with \(u=\ln x\), \(dv=x\,dx\) (for \(x>0\)):
\[
\int x\ln x\,dx=\frac{x^2}{2}\ln x-\frac{x^2}{4}+C.
\]
3. Use \(u=x^2+1\), \(du=2x\,dx\):
\[
\int\frac{x}{\sqrt{x^2+1}}\,dx=\sqrt{x^2+1}+C.
\]
