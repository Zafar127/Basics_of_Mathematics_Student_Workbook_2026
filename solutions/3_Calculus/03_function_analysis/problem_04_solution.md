# Problem 4 — A Function with Two Vertical Asymptotes

## Solution

The domain is \(\mathbb R\setminus\{-1,1\}\). The vertical asymptotes are \(x=\pm1\), and \(y=0\) is the horizontal asymptote as \(x\to\pm\infty\). The function is positive on \((-\infty,-1)\cup(1,\infty)\) and negative on \((-1,1)\).

\[
f'(x)=\frac{-2x}{(x^2-1)^2}.
\]
It is positive for \(x<0\) and negative for \(x>0\), so \(f\) increases on \((-\infty,-1)\) and \((-1,0)\), and decreases on \((0,1)\) and \((1,\infty)\). The domain is split by its two excluded points, so continuity and monotonicity must be considered separately on each component; \(x=0\) is a local maximum with value \(-1\).
