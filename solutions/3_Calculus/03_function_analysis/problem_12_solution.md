# Problem 12 — A Function with an Absolute Value

## Solution

\[
f(x)=|x^2-4|=
\begin{cases}
x^2-4,&|x|\ge2,\\
4-x^2,&|x|<2.
\end{cases}
\]
The graph of \(x^2-4\) lies below the \(x\)-axis between \(-2\) and \(2\); absolute value reflects that portion above the axis. The zeros \((-2,0)\) and \((2,0)\) become sharp cusps and global minima. The derivative is \(2x\) outside that interval and \(-2x\) inside; at either join the one-sided derivatives differ, so \(f'\) does not exist at \(x=\pm2\).
