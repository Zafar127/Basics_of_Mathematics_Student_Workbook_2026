# Exercise 8 — A Square Root in a Function Limit

## Solution

Rationalizing gives
\[
\frac{\sqrt{x}-2}{x-4}
=\frac{(\sqrt{x}-2)(\sqrt{x}+2)}{(x-4)(\sqrt{x}+2)}
=\frac1{\sqrt{x}+2}\quad(x\ne4).
\]
Hence the limit is \(1/4\). As in the sequence problem, multiplication by the conjugate removes a difference that vanishes; here it factors \(x-4\), which cancels.
