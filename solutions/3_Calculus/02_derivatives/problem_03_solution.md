# Problem 3 — The Product Rule

## Question

For
$$f(x)=(x^2+1)e^x$$
compute the derivative. Then compare the correct result with the incorrect idea
$$f'(x)\stackrel{?}{=}(2x)e^x$$
and explain which term is missing.

## Solution

The product rule gives
\[
f'(x)=2xe^x+(x^2+1)e^x=e^x(x^2+2x+1).
\]
Differentiating only \(x^2+1\) and multiplying by \(e^x\) misses the term \((x^2+1)e^x\), which comes from differentiating the exponential factor.
