# Problem 9 — An Oblique Asymptote

## Solution

Polynomial division gives
\[
\frac{x^2+1}{x-1}=x+1+\frac2{x-1}.
\]
The remainder term tends to zero as \(x\to\pm\infty\), so the oblique asymptote is \(y=x+1\). The denominator vanishes at \(x=1\), where the numerator is nonzero, giving vertical asymptote \(x=1\). There is no horizontal asymptote.
