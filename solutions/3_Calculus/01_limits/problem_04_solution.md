# Exercise 4 — Powers and Oscillation

## Solution

- \((2/3)^n\to0\), since powers of a number with absolute value less than \(1\) tend to zero.
- \((3/2)^n\to+\infty\), since its base is greater than \(1\).
- \((-1)^n\) alternates between \(-1\) and \(1\), so it has no limit.
- \((-1)^n/n\to0\), because its absolute value is \(1/n\to0\). The signs oscillate, but the amplitude shrinks to zero.
