# Exercise 5 — The Classical Limit Leading to \(e\)

## Question

Compute
$$\lim_{n\to\infty}\left(1+\frac1n\right)^n.$$
Calculate several values for increasing $n$ and compare the observed behavior with the value of the limit. Explain why a few values do not constitute a proof.

## Solution

\[
\lim_{n\to\infty}\left(1+\frac1n\right)^n=e.
\]
For example, the values for \(n=1,2,10,100,1000\) are approximately \(2,\ 2.25,\ 2.594,\ 2.705,\ 2.717\), approaching \(e\approx2.71828\). These computations support the conjecture but do not prove it: a finite list cannot establish the behavior for every sufficiently large \(n\).
