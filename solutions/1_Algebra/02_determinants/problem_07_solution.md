# Exercise 7 — Using Determinant Properties

## Question

Suppose that for a $3\times3$ matrix, $\det A=-4$. Compute
$$\det(2A),\qquad \det(A^T),\qquad \det(A^2),\qquad \det(-A).$$
Justify each answer using the appropriate property.

## Solution

For a \(3\times3\) matrix, \(\det(cA)=c^3\det A\), and transposition preserves determinant:
\[
\det(2A)=2^3(-4)=-32,\qquad
\det(A^T)=-4.
\]
By multiplicativity, \(\det(A^2)=\det(A)\det(A)=(-4)^2=16\), while
\[
\det(-A)=(-1)^3\det A=4.
\]
