# Problem 6 — Average Value of a Function

## Question

Compute the average value of the function
$$
f(x)=x^2
$$
on the interval $[0,3]$.

Find a point $c\in[0,3]$ for which $f(c)$ is equal to this average value, and interpret the result geometrically.

## Solution

The average value on \([0,3]\) is
\[
f_{\mathrm{avg}}=\frac1{3-0}\int_0^3x^2\,dx
=\frac13\left[\frac{x^3}{3}\right]_0^3=3.
\]
Solving \(c^2=3\) in the interval gives \(c=\sqrt3\). Geometrically, a rectangle of width \(3\) and height \(3\) has the same area as the region under \(y=x^2\) on \([0,3]\); at \(x=\sqrt3\), the graph reaches that average height.
