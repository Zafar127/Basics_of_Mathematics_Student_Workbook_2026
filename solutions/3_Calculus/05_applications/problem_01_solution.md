# Problem 1 — Motion: Position, Velocity, and Acceleration

## Solution

Differentiate position:
\[
v(t)=s'(t)=3t^2-12t+9=3(t-1)(t-3),\qquad
a(t)=v'(t)=6t-12.
\]
The point stops when \(v(t)=0\), at \(t=1\) and \(t=3\). For \(t\ge0\), \(v>0\) on \([0,1)\) and \((3,\infty)\), so it moves in the positive direction there; \(v<0\) on \((1,3)\), so it moves in the negative direction.
