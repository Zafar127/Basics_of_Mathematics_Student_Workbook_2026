# Exercise 2 — Formula for a \(2\times2\) Matrix

\[
\det A=3\cdot4-2\cdot5=2,\qquad
A^{-1}=\frac12\begin{pmatrix}4&-2\\-5&3\end{pmatrix}
=\begin{pmatrix}2&-1\\-\frac52&\frac32\end{pmatrix}.
\]
Verification:
\[
AA^{-1}=\begin{pmatrix}3&2\\5&4\end{pmatrix}
\begin{pmatrix}2&-1\\-\frac52&\frac32\end{pmatrix}
=I.
\]
