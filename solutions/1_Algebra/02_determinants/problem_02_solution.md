# Exercise 2 — Determinant of a \(3\times3\) Matrix

By Sarrus' rule,
\[
\det A=(1\cdot3\cdot5+2\cdot4\cdot2+(-1)\cdot0\cdot1)
-((-1)\cdot3\cdot2+2\cdot0\cdot5+1\cdot4\cdot1)=31-(-2)=33.
\]

As a check using a row-addition operation, replace \(R_3\) by \(R_3-2R_1\), which preserves the determinant. The resulting matrix has first column \((1,0,0)^T\), and its remaining \(2\times2\) determinant is \(3\cdot7-4(-3)=33\).
