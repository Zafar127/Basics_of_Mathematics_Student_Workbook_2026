# Problem 13 — A Logarithm and an Asymptote

## Solution

The domain is \(x>0\). Differentiating,
\[
f'(x)=\frac{1-\ln x}{x^2}.
\]
Thus \(f\) increases on \((0,e)\), decreases on \((e,\infty)\), and has global maximum \(f(e)=1/e\). As \(x\to0^+\), \(\ln x/x\to-\infty\); as \(x\to\infty\), \(\ln x/x\to0^+\). Therefore \(x=0\) is a vertical boundary asymptote, and \(y=0\) is a horizontal asymptote at \(+\infty\). These limits, the domain, and the maximum are key to a correct sketch.
