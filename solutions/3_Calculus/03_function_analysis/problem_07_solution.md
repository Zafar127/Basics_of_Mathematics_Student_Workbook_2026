# Problem 7 — A Trigonometric Function

## Question

On $[0,2\pi]$, find the intervals of monotonicity and the extrema of
$$f(x)=\sin x+\cos x.$$
Include the endpoints of the interval and compare the function values at the critical points and at the endpoints.

## Solution

\[
f'(x)=\cos x-\sin x=0
\quad\Longleftrightarrow\quad x=\frac\pi4,\frac{5\pi}4
\quad\text{on }[0,2\pi].
\]
Using \(\cos x-\sin x=\sqrt2\cos(x+\pi/4)\), the derivative has signs \(+,-,+\) on \((0,\pi/4)\), \((\pi/4,5\pi/4)\), and \((5\pi/4,2\pi)\). Thus the function increases, decreases, then increases; the sign changes identify a local maximum at \(\pi/4\) and a local minimum at \(5\pi/4\). Values are
\[
f(0)=f(2\pi)=1,\quad f(\pi/4)=\sqrt2,\quad f(5\pi/4)=-\sqrt2.
\]
Thus the absolute maximum is \(\sqrt2\) at \(\pi/4\), and the absolute minimum is \(-\sqrt2\) at \(5\pi/4\). The endpoints must also be checked on a closed interval.
