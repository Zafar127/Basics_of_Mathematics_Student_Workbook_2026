# Exercise 14 — A System of Equations and the Determinant

\[
\det A=4-2k.
\]
For \(k\ne2\), \(A\) is invertible, so there is exactly one solution for every \(b\).

For \(k=2\), the equations are \(x+2y=b_1\) and \(2x+4y=b_2\). For \(b=(1,2)^T\), the second equation duplicates the first, giving infinitely many solutions. For \(b=(1,3)^T\), doubling the first equation would require \(2=3\), so there is no solution.
