# Exercise 10 — Continuity of a Piecewise Function

## Question

Find $a$ so that
$$f(x)=\begin{cases}ax+1,&x<2,\\x^2-1,&x\ge2\end{cases}$$
is continuous at $x=2$. Explicitly compare the left-hand limit, right-hand limit, and function value.

## Solution

At \(x=2\), the left-hand limit is \(2a+1\). The right-hand limit and function value are both \(2^2-1=3\). Continuity requires \(2a+1=3\), so \(a=1\). For that value, the left-hand limit, right-hand limit, and \(f(2)\) all equal \(3\).
