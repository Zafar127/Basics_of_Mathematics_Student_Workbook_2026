# Exercise 4 — Triangular Matrix

## Question

Without expanding the determinant, compute
$$\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}.$$
State the rule for an arbitrary triangular matrix and explain it using this example.

## Solution

For a triangular matrix, the determinant is the product of its diagonal entries:
\[
\det A=2(-3)(7)=-42.
\]
In this upper-triangular matrix, all entries below the diagonal are zero. Consequently, in the determinant expansion only the product of diagonal entries contributes. The same rule holds for any upper- or lower-triangular matrix.
