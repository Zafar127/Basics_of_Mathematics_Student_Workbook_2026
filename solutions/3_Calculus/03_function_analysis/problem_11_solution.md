# Problem 11 — A Parameter and the Number of Extrema

## Solution

\[
f_a'(x)=3(x^2-a).
\]
- If \(a>0\), there are two critical points \(x=\pm\sqrt a\). The derivative is positive outside these points and negative between them, so \(x=-\sqrt a\) is a local maximum and \(x=\sqrt a\) a local minimum.
- If \(a=0\), the only critical point is \(0\); \(f_0'(x)=3x^2\ge0\), so it is a stationary inflection point, not an extremum.
- If \(a<0\), \(x^2-a>0\) for all \(x\), so there are no critical points and the function is strictly increasing.

The graph changes from monotone to having a maximum and minimum when the derivative's two roots become real.
