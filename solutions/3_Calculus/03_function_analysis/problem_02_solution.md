# Problem 2 — A Parabola and Its Minimum

## Question

For $f(x)=x^2-4x+1$, find the minimum using the derivative. Compare the result with the vertex form and explain why both approaches lead to the same point.

## Solution

\[
f'(x)=2x-4=0\quad\Longrightarrow\quad x=2.
\]
Since \(f''(x)=2>0\), this is the minimum, with \(f(2)=-3\). Completing the square gives \(x^2-4x+1=(x-2)^2-3\), which has the same vertex and minimum.

The vertex form is at least \(-3\) because \((x-2)^2\ge0\), with equality only at \(x=2\). The derivative gives the same conclusion by showing that \(f'\) changes from negative to positive at \(x=2\); both methods therefore locate the minimum at \((2,-3)\).
