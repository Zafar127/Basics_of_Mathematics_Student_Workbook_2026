# Problem 2 — Powers, Roots, and the Domain

## Solution

Write \(f(x)=2x^{1/2}-3x^{-2}+x^{3/2}\). The square root requires \(x\ge0\), while \(x^{-2}\) excludes \(0\); hence the domain is \((0,\infty)\). Differentiating term by term,
\[
f'(x)=x^{-1/2}+6x^{-3}+\frac32x^{1/2}.
\]
All terms are defined for \(x>0\), so the derivative has the same domain \((0,\infty)\).
