# Problem 6 — A Logarithmic Function

## Solution

The logarithm requires \(x>0\), so the domain is \((0,\infty)\). The zero solves \(\ln x-x+1=0\); \(x=1\) is the only one, since
\[
f'(x)=\frac1x-1=\frac{1-x}{x}
\]
is positive on \((0,1)\) and negative on \((1,\infty)\). Thus \(f\) increases then decreases and has maximum \(f(1)=0\). Starting with the domain ensures the logarithm and all derivative and limit arguments are used only where they are defined.
