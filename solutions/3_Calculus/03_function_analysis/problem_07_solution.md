# Problem 7 — A Trigonometric Function

## Solution

\[
f'(x)=\cos x-\sin x=0
\quad\Longleftrightarrow\quad x=\frac\pi4,\frac{5\pi}4
\quad\text{on }[0,2\pi].
\]
The function decreases on \((\pi/4,5\pi/4)\) and increases on \((0,\pi/4)\) and \((5\pi/4,2\pi)\). Values are
\[
f(0)=f(2\pi)=1,\quad f(\pi/4)=\sqrt2,\quad f(5\pi/4)=-\sqrt2.
\]
Thus the absolute maximum is \(\sqrt2\) at \(\pi/4\), and the absolute minimum is \(-\sqrt2\) at \(5\pi/4\). The endpoints must also be checked on a closed interval.
