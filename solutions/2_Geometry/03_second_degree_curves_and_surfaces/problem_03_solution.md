# Exercise 3 — Ellipse

## Question

For \(\frac{x^2}{25}+\frac{y^2}{9}=1\), find the semiaxis lengths and coordinate-axis intercepts, make a labelled sketch, and explain which axis is longer.

## Solution

The semiaxis lengths are \(5\) along the \(x\)-axis and \(3\) along the \(y\)-axis. Setting \(y=0\) gives \(x=\pm5\); setting \(x=0\) gives \(y=\pm3\). Sketch a centered ellipse through \((\pm5,0)\) and \((0,\pm3)\), stretched farther horizontally because \(25>9\).

```text
                    y
                    ^
                  (0,3) *
               .----------.
(-5,0) *------'-----O------'------* (5,0)  -> x
         <------- a=5 ------->
                    | b=3
               '----------'
                  (0,-3) *
```

The horizontal semiaxis is \(5\) and the vertical semiaxis is \(3\), so the longer axis is visibly horizontal.
